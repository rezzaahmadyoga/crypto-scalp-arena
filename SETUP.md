# Crypto Scalp Arena - Setup & Deployment Guide\n\n## Prerequisites\n\n- Python 3.11+\n- Docker & Docker Compose (untuk containerized deployment)\n- Redis 7+ (untuk local development)\n- PostgreSQL 14+ (untuk production)\n- Node.js 18+ (untuk dashboard frontend)\n- Telegram Bot Token (dari BotFather)\n- Binance API Key (optional, untuk live trading)\n\n## Local Development Setup\n\n### 1. Clone Repository\n\n```bash\ngit clone https://github.com/yourusername/crypto-scalp-arena.git\ncd crypto-scalp-arena\n```\n\n### 2. Setup Python Environment\n\n```bash\n# Create virtual environment\npython3 -m venv venv\n\n# Activate virtual environment\nsource venv/bin/activate  # On Windows: venv\\Scripts\\activate\n\n# Install dependencies\npip install -r requirements.txt\n```\n\n### 3. Setup Environment Variables\n\n```bash\n# Copy example env file\ncp .env.example .env\n\n# Edit .env with your configuration\nnano .env\n```\n\n**Required environment variables:**\n\n```env\n# Telegram Configuration\nTELEGRAM_BOT_TOKEN=your_bot_token_from_botfather\nTELEGRAM_CHAT_ID=your_chat_id\n\n# Trading Configuration\nEXCHANGE_NAME=binance\nINITIAL_CASH=1000\nTRADING_SYMBOLS=BTC/USDT,ETH/USDT,BNB/USDT,SOL/USDT,XRP/USDT,ADA/USDT\nTIMEFRAME=5m\n\n# Redis Configuration\nREDIS_URL=redis://localhost:6379/0\n\n# API Configuration\nAPI_HOST=0.0.0.0\nAPI_PORT=8000\n```\n\n### 4. Start Services Locally\n\n**Option A: Using Docker Compose (Recommended)**\n\n```bash\n# Build and start all services\ndocker-compose up -d\n\n# View logs\ndocker-compose logs -f\n\n# Stop services\ndocker-compose down\n```\n\n**Option B: Manual Setup**\n\nTerminal 1 - Redis:\n```bash\nredis-server\n```\n\nTerminal 2 - Data Feed:\n```bash\npython -m src.services.data_feed\n```\n\nTerminal 3 - Arena Manager:\n```bash\npython -m src.services.arena_manager\n```\n\nTerminal 4 - Telegram Service:\n```bash\npython -m src.services.telegram_service\n```\n\nTerminal 5 - API Server:\n```bash\npython -m src.services.api_server\n```\n\n### 5. Access Services\n\n- **API Server**: http://localhost:8000\n- **API Docs**: http://localhost:8000/docs\n- **WebSocket**: ws://localhost:8000/ws/performance\n\n## Testing\n\n### Run Unit Tests\n\n```bash\npytest tests/ -v --cov=src\n```\n\n### Run Specific Test\n\n```bash\npytest tests/test_portfolio.py -v\n```\n\n### Test with Coverage Report\n\n```bash\npytest tests/ --cov=src --cov-report=html\nopen htmlcov/index.html\n```\n\n## Cloud Deployment\n\n### Google Cloud Run Deployment\n\n#### 1. Setup Google Cloud Project\n\n```bash\n# Install gcloud CLI\n# https://cloud.google.com/sdk/docs/install\n\n# Initialize gcloud\ngcloud init\n\n# Set project\ngcloud config set project YOUR_PROJECT_ID\n```\n\n#### 2. Setup Cloud SQL (PostgreSQL)\n\n```bash\n# Create Cloud SQL instance\ngcloud sql instances create crypto-scalp-db \\\n  --database-version=POSTGRES_15 \\\n  --tier=db-f1-micro \\\n  --region=us-central1\n\n# Create database\ngcloud sql databases create crypto_scalp_arena \\\n  --instance=crypto-scalp-db\n\n# Create user\ngcloud sql users create crypto_user \\\n  --instance=crypto-scalp-db \\\n  --password=YOUR_SECURE_PASSWORD\n```\n\n#### 3. Setup Cloud Memorystore (Redis)\n\n```bash\n# Create Redis instance\ngcloud redis instances create crypto-scalp-redis \\\n  --size=1 \\\n  --region=us-central1\n```\n\n#### 4. Deploy to Cloud Run\n\n```bash\n# Build and push Docker image\ngcloud builds submit --tag gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena\n\n# Deploy services\ngcloud run deploy crypto-scalp-data-feed \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --command python,-m,src.services.data_feed \\\n  --memory 512Mi \\\n  --timeout 3600 \\\n  --set-env-vars REDIS_URL=redis://YOUR_REDIS_IP:6379/0\n\ngcloud run deploy crypto-scalp-arena-manager \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --command python,-m,src.services.arena_manager \\\n  --memory 512Mi \\\n  --timeout 3600\n\ngcloud run deploy crypto-scalp-api \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --command python,-m,src.services.api_server \\\n  --memory 512Mi \\\n  --port 8000 \\\n  --allow-unauthenticated\n```\n\n### Render.com Deployment\n\n#### 1. Connect GitHub Repository\n\n- Go to https://render.com\n- Click \"New +\" → \"Web Service\"\n- Connect your GitHub repository\n\n#### 2. Configure Service\n\n```yaml\nName: crypto-scalp-arena\nEnvironment: Docker\nBuild Command: docker build -t crypto-scalp-arena .\nStart Command: python -m src.services.api_server\nPlan: Free/Paid\n```\n\n#### 3. Add Environment Variables\n\nIn Render dashboard, add:\n- `TELEGRAM_BOT_TOKEN`\n- `TELEGRAM_CHAT_ID`\n- `REDIS_URL`\n- `DATABASE_URL`\n\n#### 4. Deploy\n\n- Click \"Create Web Service\"\n- Render will automatically deploy on every push to main branch\n\n## Monitoring & Logging\n\n### View Logs\n\n```bash\n# Docker Compose\ndocker-compose logs -f service_name\n\n# Local\ntail -f logs/trading.log\n```\n\n### Monitor Performance\n\n```bash\n# Check API health\ncurl http://localhost:8000/health\n\n# Get arena performance\ncurl http://localhost:8000/api/arena/performance\n\n# Get strategies performance\ncurl http://localhost:8000/api/strategies/performance\n```\n\n## Troubleshooting\n\n### Redis Connection Error\n\n```bash\n# Check if Redis is running\nredis-cli ping\n\n# Start Redis if not running\nredis-server\n```\n\n### Database Connection Error\n\n```bash\n# Check PostgreSQL connection\npsql -U crypto_user -d crypto_scalp_arena -h localhost\n\n# Verify DATABASE_URL in .env\n```\n\n### Telegram Bot Not Sending Messages\n\n```bash\n# Verify bot token\ncurl https://api.telegram.org/botYOUR_TOKEN/getMe\n\n# Check chat ID\n# Send message to bot and check logs\n```\n\n### High Memory Usage\n\n- Reduce `INITIAL_CASH` to lower portfolio value\n- Reduce number of trading symbols\n- Increase update interval in data feed\n\n### Slow Performance\n\n- Check Redis memory usage: `redis-cli info memory`\n- Check database query performance\n- Increase API server workers: `--workers 4`\n\n## Maintenance\n\n### Backup Database\n\n```bash\n# PostgreSQL backup\npg_dump -U crypto_user crypto_scalp_arena > backup.sql\n\n# Restore\npsql -U crypto_user crypto_scalp_arena < backup.sql\n```\n\n### Update Dependencies\n\n```bash\npip install --upgrade -r requirements.txt\n```\n\n### Clean Old Data\n\n```bash\n# Remove trades older than 30 days\npsql -U crypto_user crypto_scalp_arena -c \\\n  \"DELETE FROM trades WHERE entry_time < NOW() - INTERVAL '30 days';\"\n```\n\n## Performance Optimization\n\n### Database Indexing\n\n```sql\nCREATE INDEX idx_trades_symbol ON trades(symbol);\nCREATE INDEX idx_trades_strategy ON trades(strategy_id);\nCREATE INDEX idx_trades_timestamp ON trades(entry_time);\n```\n\n### Redis Optimization\n\n```bash\n# Set max memory policy\nredis-cli CONFIG SET maxmemory-policy allkeys-lru\n\n# Monitor memory\nredis-cli INFO memory\n```\n\n### API Performance\n\n- Enable caching: `@cache.cached(timeout=60)`\n- Use connection pooling\n- Implement pagination for large datasets\n\n## Security\n\n### API Security\n\n- [ ] Enable HTTPS/SSL\n- [ ] Implement API rate limiting\n- [ ] Add authentication/authorization\n- [ ] Validate all inputs\n\n### Database Security\n\n- [ ] Use strong passwords\n- [ ] Enable SSL connections\n- [ ] Regular backups\n- [ ] Restrict network access\n\n### Telegram Security\n\n- [ ] Never commit bot token to git\n- [ ] Use environment variables\n- [ ] Rotate token if compromised\n\n## Scaling\n\n### Horizontal Scaling\n\n- Deploy multiple API server instances behind load balancer\n- Use managed Redis (Cloud Memorystore, ElastiCache)\n- Use managed PostgreSQL (Cloud SQL, RDS)\n\n### Vertical Scaling\n\n- Increase machine resources (CPU, RAM)\n- Optimize code and queries\n- Use caching layers\n\n## Support\n\nFor issues or questions:\n\n- 📧 Email: support@cryptoscalp.local\n- 💬 Telegram: @cryptoscalp_support\n- 🐛 GitHub Issues: [Report Issue](https://github.com/yourusername/crypto-scalp-arena/issues)\n
