# Deploy ke Render.com - Step by Step Guide\n\n## ⚡ Quick Deploy (5 menit)\n\n### Step 1: Push ke GitHub\n\nKode sudah siap di GitHub: `https://github.com/rezzaahmadyoga/crypto-scalp-arena`\n\nJika belum ada, jalankan:\n```bash\ngit push -u origin main\n```\n\n### Step 2: Buka Render.com\n\n1. Go to https://render.com\n2. Sign up / Login dengan GitHub account Anda\n3. Authorize Render untuk akses repository\n\n### Step 3: Deploy Services\n\n#### Service 1: API Server (Web Service)\n\n1. Dashboard Render → Click \"New +\" → \"Web Service\"\n2. Select repository: `crypto-scalp-arena`\n3. Configure:\n   - **Name**: `crypto-scalp-api`\n   - **Environment**: `Docker`\n   - **Region**: `Oregon` (us-west)\n   - **Plan**: `Free`\n   - **Build Command**: Leave default\n   - **Start Command**: Leave default (uses Dockerfile)\n\n4. Click \"Create Web Service\"\n5. Wait for deployment (2-3 minutes)\n\n#### Service 2: Arena Manager (Background Worker)\n\n1. Dashboard Render → Click \"New +\" → \"Background Worker\"\n2. Select repository: `crypto-scalp-arena`\n3. Configure:\n   - **Name**: `crypto-scalp-arena-manager`\n   - **Environment**: `Docker`\n   - **Region**: `Oregon`\n   - **Plan**: `Free`\n   - **Start Command**: `python -m src.services.arena_manager`\n\n4. Click \"Create Background Worker\"\n\n#### Service 3: Data Feed (Background Worker)\n\n1. Dashboard Render → Click \"New +\" → \"Background Worker\"\n2. Select repository: `crypto-scalp-arena`\n3. Configure:\n   - **Name**: `crypto-scalp-data-feed`\n   - **Environment**: `Docker`\n   - **Region**: `Oregon`\n   - **Plan**: `Free`\n   - **Start Command**: `python -m src.services.data_feed`\n\n4. Click \"Create Background Worker\"\n\n#### Service 4: Telegram Service (Background Worker)\n\n1. Dashboard Render → Click \"New +\" → \"Background Worker\"\n2. Select repository: `crypto-scalp-arena`\n3. Configure:\n   - **Name**: `crypto-scalp-telegram`\n   - **Environment**: `Docker`\n   - **Region**: `Oregon`\n   - **Plan**: `Free`\n   - **Start Command**: `python -m src.services.telegram_service`\n\n4. Click \"Create Background Worker\"\n\n### Step 4: Setup PostgreSQL Database\n\n1. Dashboard Render → Click \"New +\" → \"PostgreSQL\"\n2. Configure:\n   - **Name**: `crypto-scalp-db`\n   - **Database**: `crypto_scalp_arena`\n   - **User**: `crypto_user`\n   - **Plan**: `Free`\n\n3. Click \"Create Database\"\n4. Copy connection string (akan digunakan di Step 5)\n\n### Step 5: Setup Redis\n\n1. Dashboard Render → Click \"New +\" → \"Redis\"\n2. Configure:\n   - **Name**: `crypto-scalp-redis`\n   - **Plan**: `Free`\n\n3. Click \"Create Redis\"\n4. Copy connection string (akan digunakan di Step 6)\n\n### Step 6: Add Environment Variables\n\nUntuk **setiap service** (API, Arena Manager, Data Feed, Telegram):\n\n1. Open service → Settings → Environment\n2. Add these variables:\n\n```\nTELEGRAM_BOT_TOKEN=8602463308:AAFyOTLZ9oNo7BtAmlk6t-W01iT8fxcbIyk\nTELEGRAM_CHAT_ID=1402991511\nEXCHANGE_NAME=binance\nINITIAL_CASH=1000\nTRADING_SYMBOLS=BTC/USDT,ETH/USDT,BNB/USDT,SOL/USDT,XRP/USDT,ADA/USDT\nTIMEFRAME=5m\nREDIS_URL=redis://YOUR_REDIS_CONNECTION_STRING\nAPI_HOST=0.0.0.0\nAPI_PORT=8000\nLOG_LEVEL=INFO\n```\n\n**Replace:**\n- `YOUR_REDIS_CONNECTION_STRING` dengan Redis URL dari Step 5\n\n### Step 7: Test Deployment\n\nSetelah semua services deployed (hijau):\n\n```bash\n# Test API health\ncurl https://crypto-scalp-api.onrender.com/health\n\n# Get performance metrics\ncurl https://crypto-scalp-api.onrender.com/api/arena/performance\n```\n\n### Step 8: Monitor Telegram Reports\n\nBot akan mulai mengirim laporan ke Telegram Anda:\n- 📈 Trade execution alerts\n- 📊 Daily performance reports (setiap jam)\n- ⚠️ Risk alerts\n\n## 🔍 Monitoring\n\n### View Logs\n\n1. Open service di Render dashboard\n2. Click \"Logs\" tab\n3. Scroll untuk melihat real-time logs\n\n### Check Service Status\n\n1. Dashboard Render\n2. Lihat status setiap service (harus hijau)\n3. Jika ada error, click service → Logs untuk debug\n\n## 🛠️ Troubleshooting\n\n### Service tidak start\n\n1. Check logs: Dashboard → Service → Logs\n2. Common issues:\n   - Missing environment variables\n   - Redis/Database connection error\n   - Telegram token invalid\n\n### Telegram bot tidak mengirim pesan\n\n1. Verify bot token: `curl https://api.telegram.org/botYOUR_TOKEN/getMe`\n2. Check chat ID: Pastikan format benar (harus number)\n3. View logs: Check Telegram service logs\n\n### Redis connection error\n\n1. Copy Redis URL yang benar dari Render dashboard\n2. Update di semua services\n3. Restart services\n\n### Database connection error\n\n1. Copy PostgreSQL connection string yang benar\n2. Update `DATABASE_URL` environment variable\n3. Restart services\n\n## 📊 Expected Output\n\nSetelah deployment berhasil, Anda akan menerima Telegram message seperti:\n\n```\n🤖 Crypto Scalp Arena Bot started!\n\n📈 Trade Executed\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\nSymbol: BTC/USDT\nSide: BUY\nPrice: $45,230.50\nQuantity: 0.0221\nStrategy: EMA Crossover\nTime: 2026-04-20 10:30:45\n\n📊 Daily Performance Report\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━\nDate: 2026-04-20\n\nArena Summary:\n• Total Bots: 36 (6 strategies × 6 symbols)\n• Portfolio Value: $1,050.25\n• Total Trades: 24\n• Average ROI: +5.03%\n\nTop Performer: EMA Crossover (+8.2%)\nWorst Performer: Price Action (-2.1%)\n```\n\n## 💰 Cost\n\n- **API Server**: Free (512MB RAM, shared CPU)\n- **Background Workers**: Free (0.5 CPU, 512MB RAM each)\n- **PostgreSQL**: Free (1GB storage)\n- **Redis**: Free (256MB)\n- **Total**: $0/month ✅\n\n## 🚀 Next Steps\n\n1. ✅ Deploy to Render.com\n2. ✅ Monitor Telegram reports\n3. ✅ Watch live paper trading\n4. ⏳ Optimize strategies (AI optimizer)\n5. ⏳ Consider live trading (with caution!)\n\n## 📞 Support\n\nJika ada masalah:\n1.
