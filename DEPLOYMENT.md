# Crypto Scalp Arena - Cloud Deployment Guide\n\n## Quick Start: Deploy to Render.com (Recommended for Beginners)\n\nRender.com menyediakan free tier yang cukup untuk paper trading bot.\n\n### Step 1: Prepare Repository\n\n```bash\n# Initialize git if not already done\ngit init\ngit add .\ngit commit -m \"Initial commit: Crypto Scalp Arena\"\n\n# Push to GitHub\ngit remote add origin https://github.com/yourusername/crypto-scalp-arena.git\ngit push -u origin main\n```\n\n### Step 2: Create Render Account\n\n1. Go to https://render.com\n2. Sign up with GitHub account\n3. Authorize Render to access your repositories\n\n### Step 3: Create Services\n\n#### Service 1: API Server (Web Service)\n\n1. Click \"New +\" → \"Web Service\"\n2. Select your repository\n3. Configure:\n   - **Name**: `crypto-scalp-api`\n   - **Environment**: `Docker`\n   - **Region**: `Oregon` (us-west)\n   - **Plan**: `Free`\n   - **Build Command**: `docker build -t crypto-scalp-arena .`\n   - **Start Command**: `python -m src.services.api_server`\n\n4. Click \"Create Web Service\"\n\n#### Service 2: Arena Manager (Background Worker)\n\n1. Click \"New +\" → \"Background Worker\"\n2. Select same repository\n3. Configure:\n   - **Name**: `crypto-scalp-arena-manager`\n   - **Environment**: `Docker`\n   - **Start Command**: `python -m src.services.arena_manager`\n   - **Plan**: `Free`\n\n4. Click \"Create Background Worker\"\n\n#### Service 3: Data Feed (Background Worker)\n\n1. Click \"New +\" → \"Background Worker\"\n2. Select same repository\n3. Configure:\n   - **Name**: `crypto-scalp-data-feed`\n   - **Environment**: `Docker`\n   - **Start Command**: `python -m src.services.data_feed`\n   - **Plan**: `Free`\n\n4. Click \"Create Background Worker\"\n\n#### Service 4: Telegram Service (Background Worker)\n\n1. Click \"New +\" → \"Background Worker\"\n2. Select same repository\n3. Configure:\n   - **Name**: `crypto-scalp-telegram`\n   - **Environment**: `Docker`\n   - **Start Command**: `python -m src.services.telegram_service`\n   - **Plan**: `Free`\n\n4. Click \"Create Background Worker\"\n\n### Step 4: Add Environment Variables\n\nFor each service, go to \"Environment\" and add:\n\n```\nTELEGRAM_BOT_TOKEN=your_bot_token\nTELEGRAM_CHAT_ID=your_chat_id\nEXCHANGE_NAME=binance\nINITIAL_CASH=1000\nTRADING_SYMBOLS=BTC/USDT,ETH/USDT,BNB/USDT,SOL/USDT,XRP/USDT,ADA/USDT\nTIMEFRAME=5m\nREDIS_URL=redis://your-redis-url:6379/0\nAPI_HOST=0.0.0.0\nAPI_PORT=8000\n```\n\n### Step 5: Add PostgreSQL Database\n\n1. Click \"New +\" → \"PostgreSQL\"\n2. Configure:\n   - **Name**: `crypto-scalp-db`\n   - **Plan**: `Free`\n\n3. Note the connection string\n4. Add to environment variables:\n   ```\n   DATABASE_URL=postgresql://user:password@host:5432/crypto_scalp_arena\n   ```\n\n### Step 6: Add Redis\n\n1. Click \"New +\" → \"Redis\"\n2. Configure:\n   - **Name**: `crypto-scalp-redis`\n   - **Plan**: `Free`\n\n3. Note the connection string\n4. Update `REDIS_URL` in all services\n\n### Step 7: Deploy\n\n1. All services will automatically deploy\n2. Monitor deployment in \"Events\" tab\n3. Once deployed, you'll get a public URL for API server\n\n### Step 8: Test Deployment\n\n```bash\n# Test API health\ncurl https://your-api-url.onrender.com/health\n\n# Get performance metrics\ncurl https://your-api-url.onrender.com/api/arena/performance\n```\n\n## Advanced: Deploy to Google Cloud Run\n\n### Prerequisites\n\n```bash\n# Install Google Cloud SDK\n# https://cloud.google.com/sdk/docs/install\n\n# Initialize\ngcloud init\ngcloud config set project YOUR_PROJECT_ID\n\n# Enable required APIs\ngcloud services enable run.googleapis.com\ngcloud services enable cloudbuild.googleapis.com\ngcloud services enable sqladmin.googleapis.com\ngcloud services enable redis.googleapis.com\n```\n\n### Step 1: Create Cloud SQL Database\n\n```bash\n# Create PostgreSQL instance\ngcloud sql instances create crypto-scalp-db \\\n  --database-version=POSTGRES_15 \\\n  --tier=db-f1-micro \\\n  --region=us-central1 \\\n  --storage-auto-increase\n\n# Create database\ngcloud sql databases create crypto_scalp_arena \\\n  --instance=crypto-scalp-db\n\n# Create user\ngcloud sql users create crypto_user \\\n  --instance=crypto-scalp-db \\\n  --password=YOUR_SECURE_PASSWORD\n\n# Get connection string\ngcloud sql instances describe crypto-scalp-db \\\n  --format='value(connectionName)'\n```\n\n### Step 2: Create Cloud Memorystore Redis\n\n```bash\n# Create Redis instance\ngcloud redis instances create crypto-scalp-redis \\\n  --size=1 \\\n  --region=us-central1 \\\n  --redis-version=7.0\n\n# Get Redis host and port\ngcloud redis instances describe crypto-scalp-redis \\\n  --region=us-central1 \\\n  --format='value(host,port)'\n```\n\n### Step 3: Build and Push Docker Image\n\n```bash\n# Configure Docker\ngcloud auth configure-docker\n\n# Build image\ndocker build -t gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena .\n\n# Push to Container Registry\ndocker push gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena\n\n# Or use Cloud Build\ngcloud builds submit --tag gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena\n```\n\n### Step 4: Deploy Services to Cloud Run\n\n```bash\n# Deploy API Server\ngcloud run deploy crypto-scalp-api \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --platform managed \\\n  --region us-central1 \\\n  --memory 512Mi \\\n  --timeout 3600 \\\n  --set-env-vars TELEGRAM_BOT_TOKEN=YOUR_TOKEN,TELEGRAM_CHAT_ID=YOUR_CHAT_ID \\\n  --allow-unauthenticated\n\n# Deploy Arena Manager\ngcloud run deploy crypto-scalp-arena-manager \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --platform managed \\\n  --region us-central1 \\\n  --memory 512Mi \\\n  --timeout 3600 \\\n  --set-env-vars TELEGRAM_BOT_TOKEN=YOUR_TOKEN,TELEGRAM_CHAT_ID=YOUR_CHAT_ID \\\n  --command python,-m,src.services.arena_manager\n\n# Deploy Data Feed\ngcloud run deploy crypto-scalp-data-feed \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --platform managed \\\n  --region us-central1 \\\n  --memory 512Mi \\\n  --timeout 3600 \\\n  --set-env-vars TELEGRAM_BOT_TOKEN=YOUR_TOKEN,TELEGRAM_CHAT_ID=YOUR_CHAT_ID \\\n  --command python,-m,src.services.data_feed\n\n# Deploy Telegram Service\ngcloud run deploy crypto-scalp-telegram \\\n  --image gcr.io/YOUR_PROJECT_ID/crypto-scalp-arena \\\n  --platform managed \\\n  --region us-central1 \\\n  --memory 512Mi \\\n  --timeout 3600 \\\n  --set-env-vars TELEGRAM_BOT_TOKEN=YOUR_TOKEN,TELEGRAM_CHAT_ID=YOUR_CHAT_ID \\\n  --command python,-m,src.services.telegram_service\n```\n\n### Step 5: Setup Cloud Scheduler for Periodic Tasks\n\n```bash\n# Create scheduler job for daily reports\ngcloud scheduler jobs create http daily-report \\\n  --location=us-central1 \\\n  --schedule=\"0 9 * * *\" \\\n  --uri=https://YOUR_API_URL/api/telegram/send-report \\\n  --http-method=POST\n```\n\n## Monitoring & Logging\n\n### View Logs\n\n**Render.com:**\n```bash\n# In Render dashboard: Logs tab\n```\n\n**Google Cloud Run:**\n```bash\n# View logs\ngcloud run logs read crypto-scalp-api --limit 50\n\n# Stream logs\ngcloud run logs read crypto-scalp-api --limit 50 --follow\n```\n\n### Setup Monitoring\n\n**Google Cloud:**\n```bash\n# Create uptime check\ngcloud monitoring uptime-checks create \\\n  --display-name=\"Crypto Scalp API\" \\\n  --resource-type=uptime-url \\\n  --monitored-resource-labels=host=YOUR_API_URL\n```\n\n## Cost Estimation\n\n### Render.com (Free Tier)\n- API Server: Free (512MB RAM, shared CPU)\n- Background Workers: Free (0.5 CPU, 512MB RAM)\n- PostgreSQL: Free (1GB storage)\n- Redis: Free (256MB)\n- **Total: $0/month** ✅\n\n### Google Cloud Run\n- API Server: ~$5-10/month\n- Background Workers: ~$5-10/month\n- Cloud SQL: ~$10-15/month\n- Cloud Memorystore: ~$5-10/month\n- **Total: ~$25-45/month**\n\n## Scaling Considerations\n\n### When to Scale Up\n\n- Portfolio value > $10,000\n- Trading > 1000 trades/month\n- Need < 100ms latency\n- Multiple users/instances\n\n### Scaling Options\n\n1. **Render.com**: Upgrade to paid plan\n2. **Google Cloud**: Increase machine size, add load balancer\n3. **AWS**: Use EC2, RDS, ElastiCache\n4. **Kubernetes**: Deploy with GKE or EKS\n\n## Disaster Recovery\n\n### Backup Strategy\n\n```bash\n# Daily database backup\ngcloud sql backups create \\\n  --instance=crypto-scalp-db \\\n  --description=\"Daily backup\"\n\n# Automated backups (set in Cloud SQL)\n# Retention: 30 days\n# Frequency: Daily at 3 AM UTC\n```\n\n### Recovery Procedure\n\n```bash\n# Restore from backup\ngcloud sql backups restore BACKUP_ID \\\n  --backup-instance=crypto-scalp-db\n```\n\n## Troubleshooting\n\n### Service Won't Start\n\n```bash\n# Check logs\ngcloud run logs read SERVICE_NAME --limit 100\n\n# Check environment variables\ngcloud run services describe SERVICE_NAME --format='value(spec.template.spec.containers[0].env)'\n```\n\n### Database Connection Error\n\n```bash\n# Test connection\npsql -h CLOUD_SQL_IP -U crypto_user -d crypto_scalp_arena\n\n# Check Cloud SQL Proxy\ngcloud sql connect crypto-scalp-db --user=crypto_user\n```\n\n### Redis Connection Error\n\n```bash\n# Test Redis\nredis-cli -h REDIS_HOST -p 6379 ping\n```\n\n## Next Steps\n\n1. ✅ Deploy system to cloud\n2. ✅ Configure Telegram notifications\n3. ✅ Monitor performance metrics\n4. ✅ Test paper trading\n5. ⏳ Optimize strategies\n6. ⏳ Consider
